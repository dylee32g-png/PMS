# 프로젝트 List 데이터 백업 운영 루틴 v1.0

- 작성: 2026-09-09 / 대상: 관리자(팀장) · 공용(메인) PC 담당자
- 근거 코드: `src/components/ProjectListScreen.jsx` (전체 백업·복원 1684행~, 자동 백업 "메인 PC 자동 전체 백업" 절)

## 1. 두 겹 백업 체계 (한눈에)

| 겹 | 누가 | 언제 | 어디에 | 담기는 것 |
|---|---|---|---|---|
| ① 주간 수동 | 관리자 | **매주 월요일 아침** | 내려받기 폴더 → **NAS 백업 폴더로 이동** | 팀 전체 (행·표구조·진행실적 장부·백로그·월간 마감본·월간보고·팀 설정) |
| ② 매일 자동 | 메인 PC(사람 없음) | **매일 06시 이후 1회** (파수꾼 05:30 재시작 뒤) | 메인 PC에 지정한 **NAS 백업 폴더에 직접 저장** | ①과 100% 동일 형식 (3팀 한 번에) |

- 두 겹 모두 파일 이름은 `PMS전체백업_팀이름_YYYYMMDD_HHMM.json`. 둘 다 [백업 복원]에 그대로 넣을 수 있음.
- 자동 백업은 90일 지난 자기 파일만 폴더에서 정리함(다른 파일·수동 백업 파일은 안 건드림. 수동 파일도 같은 이름 규칙이면 90일 뒤 정리 대상이 되므로, 오래 남길 파일은 이름을 바꾸거나 다른 폴더에 둘 것).

## 2. 주간 수동 백업 절차 (월요일, 5분)

1. 관리자 계정으로 로그인 → 아무 팀 프로젝트 List → 설정(⚙) → **[전체 백업 (JSON) · 3팀 한 번에]**
2. 크롬이 "여러 파일 다운로드 허용?"을 물으면 **허용** (첫 1회만) → 3팀 파일 3개가 내려받기 폴더에 떨어짐
3. 완료창의 팀별 숫자(행·장부·백로그 건수) 확인
4. 내려받기 폴더의 3개 파일을 NAS 백업 폴더로 이동 (예: `\\neconsys_pj\...\PMS백업\수동\`)
5. 자동 백업이 정상인지도 같이 확인: 화면 맨 아래 상태줄 `● 자동 백업 · 9/8 06:00 ✓` 처럼 **어제 또는 오늘 날짜 + ✓** 이면 정상

※ 버튼은 화면에 보이는 팀과 상관없이 항상 3팀(기술1·2·3팀)을 서버에서 읽어 백업합니다. 파일 내용은 자동 백업과 동일.

## 3. 자동 백업 켜기 (메인 PC에서 1회, 관리자)

전제: NAS 백업 폴더가 있어야 함 (예: Z:\...\PMS백업\자동). 크롬은 드라이브 루트(Z:\)를 못 고르므로 **하위 폴더**를 만들어 지정.

1. 메인 PC(공용 PC)에서 **관리자 계정**으로 로그인 → 아무 팀 프로젝트 List → 설정(⚙)
2. **[자동 백업 폴더 지정 (이 PC · 매일)]** 클릭 → 폴더 선택창에서 NAS 백업 폴더 선택 → 크롬이 "파일 수정 허용?" 물으면 **[방문할 때마다 허용]** 선택(있으면) 또는 [허용]
3. 시각 입력창: 기본 `6` (06시) 그대로 확인
4. 곧바로 첫 백업이 실행됨 → 우하단 초록 알림 `자동 백업 완료 → 폴더 '자동'` + 3팀 행·장부 건수 → NAS 폴더에 파일 3개 생겼는지 탐색기로 확인
5. 로그아웃하고 **공용 계정**으로 다시 로그인해도 자동 백업은 계속 돌아감 (켜짐 표시는 이 PC 기준 — 화면 아래 `● 자동 백업 (이 PC)`)

메뉴 안내

| 메뉴(관리자, 설정 ⚙) | 하는 일 |
|---|---|
| 자동 백업 폴더 지정 (이 PC · 매일) | 폴더·시각 지정 + 켜기 + 즉시 1회 실행. 다시 누르면 폴더 바꾸기 |
| 지금 백업 → 폴더 | 3팀 즉시 1회 (확인용·허가 다시 받기용) |
| 자동 백업 끄기 (이 PC) | 이 PC 자동 백업 중지 + 폴더 허가증 삭제 |
| (메뉴 아래 회색 줄) | 이 팀의 마지막 자동 백업 시각·결과 (클라우드 기록이라 어느 PC에서든 보임) |

## 4. 상태 확인 (모든 직원 화면 공통)

화면 맨 아래 상태줄 `● 자동 백업 · 9/9 06:00 ✓`

| 색 | 뜻 | 조치 |
|---|---|---|
| 초록 ✓ | 26시간 안에 성공 기록 있음 | 없음 |
| 주황 | 26시간 넘게 새 기록 없음 | 메인 PC가 꺼졌거나 List 화면이 아닌 상태. 메인 PC 확인 |
| 빨강 ✗ | 마지막 시도 실패 | 마우스를 올리면 사유 표시. 아래 5장 |
| 회색 | 기록 없음 | 아직 한 번도 안 돎 (3장 절차) |

## 5. 문제 해결

| 증상(알림 문구) | 원인 | 조치 |
|---|---|---|
| 이 PC에 백업 폴더가 지정되지 않았습니다 | 허가증 없음 (브라우저 데이터 삭제·다른 PC) | 3장 절차로 다시 지정 |
| 백업 폴더 쓰기 허용이 필요합니다 | 크롬 재시작 후 허가증이 '다시 물어봄'으로 돌아감 | 관리자 계정 → 설정 → [지금 백업 → 폴더] 1번 누르면 허용창 → 허용. 지정 때 [방문할 때마다 허용]을 골랐으면 재발 안 함 |
| ✗ 팀이름: (오류 메시지) | 그 팀 읽기 실패(통신·할당량) | 1시간 뒤 자동 재시도. 계속되면 Firebase 사용량 확인 |
| 주황(하루 넘게 기록 없음) | 메인 PC 꺼짐 / 홈 화면에 머묾 / 브라우저 닫힘 | 파수꾼 상태보기 .bat → List 화면으로 복귀. 다음 틱(1분)에 그날 치 따라잡음 |
| NAS 폴더에 파일이 안 늘어남 | 폴더를 로컬(내려받기 등)로 지정했거나 NAS 연결 끊김 | 설정 메뉴 회색 줄의 `→ '폴더이름'` 확인, 다시 지정 |

## 6. 되돌리기 (복원) — 관리자

1. 되돌릴 팀의 프로젝트 List → 설정 → **[백업 복원]** → NAS 폴더에서 원하는 시점의 `PMS전체백업_그팀_...json` 선택
2. 확인창의 건수(지금 N건 → 백업 M건)를 읽고 진행 → 복원 직전 현재 상태가 자동으로 한 번 더 내려받아짐(안전망)
3. 복원되는 것: 행·표 구조·진행실적 장부·월간 마감본·월간보고·팀 설정. 백로그(감사 기록)는 그대로 둠
4. 복원 후 할 일: NAS 규칙 폴더 허가증은 행 ID가 바뀌지 않으므로 보통 그대로 유효. 화면 F5 후 숫자 확인

## 7. 이 체계에 아직 없는 것 (알고 있을 빈틈)

- 백업은 팀 단위 통째 복원만 가능 (행 하나만 골라 되돌리기는 없음 → 행 변경 이력·백로그로 추적)
- Firebase 자체 백업(구글 쪽 시점 복구)은 무료 요금제라 꺼져 있음. 켜려면 Blaze 전환 + 관리자(전무님) 권한
- 자동 백업은 메인 PC 브라우저가 List 화면에 떠 있어야 돎 (파수꾼이 이를 지킴)
