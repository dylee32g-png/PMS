### 3. 팀장님 요구 3건 (선택지 4문항 = 모두 추천안으로 확정)
- **① 빈칸 = 회색만 (× 글자 제거)**
  - 빈칸·사용 안 함 칸은 회색만 칠하고 × 글자는 그리지 않음. 상세 보기 스위치 연동은 그대로.
  - x 키인 = **진행 숫자 칸만** '사용 안 함'(PLC·ETOS·HMI·Point·진행율 %·% 칸·포인트·총물량·누적 — `isProgNumCol`). 그 밖의 칸(견적 제출·공사기안·착·완 같은 O/X 칸)은 **'X' 값 저장**(x·×·ㅌ → X). 날짜 칸은 날짜 검사 그대로. 범위 x도 진행 숫자 칸만.
- **② 수행번호 직접 입력 (전 사용자)**
  - ⚙ 설정 → **입력 도구 → [수행번호 직접 입력]** → 다음 클릭 1번만 편집창이 열림(열리는 순간 자동 꺼짐 — 8/28 '엉뚱한 값' 사고 방지 유지).
  - 숫자만 쳐도 됨(2 → 26-002) · 형식 오류·중복 번호는 거부 · 지금 마지막 번호보다 크면 확인창 · [+](마지막+1)·✕는 그대로 · Esc·팀 이동 = 취소 · 켜진 동안 안내 띠.
- **③ 잘라내기(Ctrl+X) → 옮기기 + 되돌리기(Ctrl+Z)**
  - 번호 칸 클릭(행 선택) → Ctrl+X(초록 점선, Esc = 취소) → 옮길 자리의 행 번호 칸 클릭 → **Ctrl+V = 그 행 위로**(엑셀 '잘라낸 셀 삽입'과 같음, 덮어쓰기 아님). 우클릭 [이 행 위에/아래에 삽입]도 잘라낸 행이면 옮기기.
  - `planMoveRows` = **자리만 이동** → 수행번호·진행실적·이력·내부 ID 그대로. 잘라낸 행에 기대어 있던 행은 제자리.
  - 저장 전엔 번호 칸 노란 표시 · [저장 옮김 N건]/[취소] · 같은 연도 안에서만 · 옮기기 저장 전엔 붙여넣기·완전 삭제·상세 보기 저장을 막음(자리 계산 엇갈림 방지).
  - Ctrl+Z = **저장 전 작업만** 한 단계씩(한 동작 = 1단계, 100단계까지). [저장]·[취소]·팀 이동·상세 보기 저장·완전 삭제 때 기록 비움. 편집창 안에서는 글자 되돌리기.
