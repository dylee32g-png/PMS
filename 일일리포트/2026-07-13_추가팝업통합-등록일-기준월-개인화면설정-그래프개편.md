### 3. List 헤더 '기준월' 드롭다운 (전체 / 1~12월 / 기타)
- 기준 날짜 = 메인표 **공사 계약**. 기준연도 + 년·월·일이 모두 있는 날짜만 그 달로 인정.
- 기타 = 기준연도의 어느 달에도 못 들어가는 나머지 전부(빈칸, '2022년', '2025-10' 같은 불완전 날짜, 다른 해 날짜).
- → 1~12월 건수 + 기타 = 전체 건수로 정확히 일치(빠지는 행 없음). 옵션에 건수 표시.
- 월을 고르면 표뿐 아니라 진행현황 칩·담당자 탭·필터 목록 건수까지 함께 좁혀짐.

### 4. 개인 화면 설정 (이 PC에만 저장 · localStorage)
- **표 배율** 선택기(70~150%) 신설 — 헤더 '컴팩트' 옆. 한 번 고르면 그 PC에서 계속 유지.
- **열 너비** 기억 — 마우스로 끈 폭·더블클릭 자동맞춤 폭이 새로고침/재로그인 후에도 유지(팀별 저장).
- 계정·서버와 무관 → 직원 각자 자기 모니터에 맞춰 고정, 서로 영향 없음. 관리자 협의·보안규칙 변경 불필요.
- 설정 메뉴에 '내 화면 설정 초기화(배율·열너비)' 추가.

### 5. 실적 그래프 전면 개편 (개별 그래프)
- **기간 규칙**: List의 공사 계약 ~ 공사 완료를 기간으로 사용. 빈칸 규칙(계약만 → 이번 달까지 '진행중', 완료만 → 첫 실적~완료, 둘 다 없음 → 실적 기준/최근 12개월+안내), 실적이 기간 밖이면 자동 확장, 최소 3개월, 계약>완료면 경고 배지. 기간 카드에 근거 문구 표시.
  - ※'2022년'처럼 연도만 있는 값은 날짜로 인정 안 됨 → 계약일 없음 처리. 팀장님 지시로 **현행 유지(회의 후 재검토)**.
- **시인성 개편**: 달 수가 적어도 폭 채움 / 누적 = 얇은 점선 → 면적+실선 / 막대 안 중복 점 제거 / 공정률 = 흰속 점 + 초록 알약 라벨 / 총점 기준선 라벨 인그래프 / 격자·축 정렬 / 범례 칩 / 막대 툴팁.
- **축 통일(★)**: 왼쪽 축 최대 = 총점(=오른쪽 100%). 200pt면 0·50·100·150·200 / 우측 0·25·50·75·100%가 같은 높이. 초과 시에만 축 확장(100%는 총점 높이 고정).
- **줌 복구**: 폭 채우기 로직이 줌을 덮어써 먹통이던 것 수정 — 100%=폭 채움 기준, 줌은 거기에 곱셈(가로+세로+막대 굵기).
