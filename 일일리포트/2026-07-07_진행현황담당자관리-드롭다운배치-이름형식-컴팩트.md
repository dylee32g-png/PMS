## 오늘 한 일

### 1. 2단계 진행현황 관리 안전안 마무리 (어제 ① 일괄반영 폐기)
- 배경: 7/6에 시도한 '이름 변경 시 데이터 152행 일괄반영'(①안)이 confirm 건수 152→88 불안정·미반영으로 미완 → 롤백 상태였음.
- 근본원인 진단(코드 전수): 진행현황 값이 **152개 별도 클라우드(Firestore) 문서**에 흩어져 저장 + 개수 세기가 '기준연도로 걸러진 화면(yearFilteredRows)'만 셈 → 한 장씩 고치는 중 목록이 실시간 갱신돼 세던 기준이 흔들림.
- 결정: ①(실데이터 무더기 수정) 폐기, ②(안전안) 채택. 원본 엑셀에서 이름이 정리돼 오므로 이름 변경이 사실상 불필요.
- 구현: 기존 이름 **잠금**(수정 불가·🔒 표시), 새 이름만 추가·삭제·순서, 저장 시 중복 제거.
- 삭제 잠금: '배정 0개일 때만 삭제'. 사용 중인 이름의 ✕는 회색 비활성(툴팁 안내). 실데이터는 목록에서 빼도 보존.

### 2. 3단계 담당자 관리 추가 (진행현황과 동일 방식)
- 설정 메뉴에 '담당자 관리' 버튼(사람 아이콘) 신설.
- 모달: 기존 이름 잠금 + 추가/삭제/순서 + 0명일 때만 삭제. `teamSettings[팀].listManager`에 저장(onSnapshot 자동 반영).

### 3. 인라인 드롭다운 상하 자동배치 (4종 전부)
- 문제: 진행현황·담당자·발주처·업체담당자 드롭다운이 셀 '아래로만' 펼쳐져 표 마지막 줄에서 화면 밖으로 잘림.
- 해결: 공용 위치계산 `dropAnchor` 신설 — 아래 공간 부족하면 위로 펼침 + 넘치면 스크롤.
- 보완: 위로 펼 때 **클릭한 지점** 기준으로 배치 → 프로젝트 줄이 높아도 셀에서 멀어지지 않음.

### 4. 담당자 이름 형식 통일 (필터 카운트 정상화)
- 문제: 목록은 '김준혁TL'(영문코드), 데이터는 '김준혁 팀장'(한글 직책) → 안 맞아 담당자 필터 카운트 전부 0.
- 해결: `extractName`을 '순수 한글 이름' 비교로 보완(뒤 영문코드 제거 + 띄어쓰기 앞부분만). 데이터·목록 원본은 그대로, 비교 규칙만 변경.
- 검증: 목록↔데이터 9쌍 시뮬 9/9 일치. 실기기 카운트 정상(최영환DD 7·조장현TL 36·신정환C 12 등).

### 5. 삭제 잠금 기준을 화면 탭과 일치
- 문제: '염경록TL 탭은 0인데 삭제 안 됨' — 삭제잠금은 전체 연도(activeRows), 탭은 그해(yearFilteredRows)를 세서 어긋남.
- 해결: `countManagerUse`가 탭과 같은 `assigneeCountMap`(기준연도)을 재사용 → 탭이 0이면 삭제도 풀림.

### 6. 컴팩트 기능 분석 + 개선 + 검은색 버그 수정
- 전수 분석: `compactMode`(보통/컴팩트/초소형)는 주로 표 셀 상하 여백(줄 높이)을 바꿈. 본문 글자는 거의 안 변함. 매번 초기화되고 현재 모드가 안 보이는 게 비효율.
- 개선: ① localStorage로 마지막 선택 기억(컴퓨터별) ② 버튼 라벨=현재 모드 표시.
- 검은색 버그: `Number(null)=0`으로 첫 로딩이 '보통' 오인식 + '보통' 배경(`bg-slate-100`)이 이 빌드에서 미적용 → 버튼 검게. 수정: 기본값 복구(빈 값→컴팩트) + 버튼 배경을 3모드 **인라인 색**으로 직접 지정.
