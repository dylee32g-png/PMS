## 2. ★ 원인 (확정) — 오피스365 계정을 넣은 PC만 실패

**4대 PC 대조 결과, 예외 없이 갈렸습니다.**

| PC | 오피스365 계정 | [엑셀로 열기] |
|---|---|---|
| 팀장님 노트북 | **있음** (7/29 평가판) | 실패 → **오늘 해결** |

| 직원2 | 없음 | **정상** |
| 공용 PC | 없음 | **정상** |

**메커니즘**
```
365 안 넣은 PC : NAS 주소 만남 → 아이디/비번(Basic) 로그인 시도 → 성공
365 넣은 PC   : NAS 주소 만남 → "조직 계정으로 인증해야지"(Modern Auth)만 시도
                → NAS엔 조직 계정 없음 → 실패
                → Basic 로그인으로 되돌아가지 않음 → "SharePoint 사용 권한" 오류
```
로그인 창이 **아예 안 뜨는** 것이 특징 — Basic 로그인을 시도조차 하지 않는다.
엑셀 → 파일 → 계정에서 **로그아웃만 해서는 안 풀린다** (겉 계정만 지워지고 인증 방식은 조직 계정용으로 남음).

**날짜가 맞아떨어짐**: 7/28 [엑셀로 열기] 첫 성공 → **7/29 365 평가판 계정 2개 투입** → 이후 막힘.
"재부팅하면 안 된다"는 관찰은 **우연의 일치**였다(공용 PC는 365를 안 넣어서 계속 됐던 것).

## 3. ★ 해결 (팀장님 노트북 실기기 확인 완료)

일반 `cmd`(로그인 계정과 같은 창)에서 아래 2줄 → **엑셀 완전 종료** → [엑셀로 열기]:

```
reg add "HKCU\Software\Microsoft\Office\16.0\Common\Identity" /v EnableADAL /t REG_DWORD /d 0 /f
reg add "HKCU\Software\Microsoft\Office\16.0\Common\Identity" /v SignedOutADUser /t REG_DWORD /d 1 /f
```
- `EnableADAL=0` — 조직 계정(365) 인증 끄기
- `SignedOutADUser=1` — **로그아웃 상태임을 Office에 명시** ← 이것까지 넣어야 열렸다
- 되돌리기(365를 다시 쓸 때): 같은 2줄을 `reg delete ... /v <값이름> /f` 로

※ `HKCU`는 **실행한 계정**의 설정 → `.bat`이나 `cmd`를 **관리자 권한으로 실행하면 엉뚱한 계정에 등록**된다.
   팀장님 노트북은 로그인 계정 자체가 Administrator라 문제없었으나, 직원 PC는 주의.
