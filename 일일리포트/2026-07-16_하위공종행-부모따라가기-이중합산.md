## 결정·근거
- **하위 = 웹 관리**: 팝업·그래프·모바일이 요구하는 건 '행 + 실행번호 s'뿐이라 기능은 이미 준비됨. 엑셀 양식 변경은 4팀 협의·원칙(항목 임의변경 금지) 부담 + 하위 변경 때마다 재업로드(전량삭제) 반복 위험. 규칙 공통화로 엑셀 도입 가능성도 열어둠(팀장님 요청).
- **메인 POINT = 하위 총점 합계 자동** (팀장님 확정) → 2단계에서 구현.
- **기존 월간보고 하위의 List 이관 = 보류** (List가 뼈대, 월간이 최초가 되면 크로스 관리 혼선 — 팀장님).
- **하위 실적은 순번(sub_0, sub_1…)으로 저장** → 새 하위는 맨 뒤에만 추가, 순서 변경·중간 삭제 금지(과거 실적이 옆 하위로 밀림). 장기 개선 = pid 키 전환.
- 옛 메인 직접 키인 데이터는 삭제가 아니라 **집계 제외**(장부에 보존, 무해).
