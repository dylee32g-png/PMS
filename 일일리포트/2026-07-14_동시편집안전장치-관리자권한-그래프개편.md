## 오늘 한 일

### 1. 동시 편집 안전 진단 (출발점)
직원들이 각자 계정으로 로그인해 동시에 다른 프로젝트를 수정해도 안전한지 코드로 확인했다.

**결론: 서로 다른 프로젝트는 원래부터 안전하다.** 프로젝트 1건 = Firestore 문서 1개 구조이고(`rowDocRef(팀, 행ID)`), 저장은 그 문서 하나만 덮어쓴다. 화면은 `onSnapshot` 실시간 구독이라 남의 저장이 몇 초 안에 자동 반영된다.

위험 지점 3가지를 식별했다.
- 같은 프로젝트의 **같은 칸**을 동시에 고치면 나중에 저장한 사람이 이김(조용히 덮어씀)
- **엑셀 확정 저장** = 기존 전량 삭제 후 교체 → 그 시각 남의 작업 전부 소실
- **전체 저장** = 화면의 모든 행을 통째로 덮어씀

### 3. 동시수정 감지
- **수정 도장**: 모든 개별 저장 경로에 `_updatedAt` / `_updatedBy` 기록 (`stampSave`)
- **상세팝업**(`findConflicts`): 저장 직전 서버 최신본과 '팝업 열 때 원본'을 대조 → 내가 고친 칸을 남이 먼저 고쳤을 때만 빨간 확인창. 서로 **다른 칸**이면 기존 병합 로직이 양쪽 값을 모두 살린다(헛경보 없음).
- **인라인**(`findCellConflict`): 표에서 셀 직접 입력 시 **편집을 시작한 순간의 값**(`editOrigRef`)을 기준으로 비교 → 입력 중 화면이 실시간 갱신돼도 놓치지 않음. 드롭다운(진행현황·담당자)도 저장 직전 서버 확인.
- 확인창 시간 표시를 UTC → 한국시간으로 수정
- 역방향 동기화(공정률 → 진행실적 주차장부)를 **저장 확정 후**로 이동 → 충돌 [취소] 시 장부만 바뀌던 순서 문제 해결

**실기기 확인**: 두 계정으로 같은 담당자 칸 수정 → 빨간 창 정상 표시.
드롭다운은 원리상 경고가 거의 안 뜬다(클릭=즉시 저장이라 "내가 본 값"이 곧 최신값). 이는 정상 동작.

### 4. 로그인 유지 (재인증 불필요)
이메일 링크 로그인은 **탭이 2개** 관여한다. 로그인 화면(탭 A)에서 persistence를 설정하지만, 실제 로그인이 완료되는 곳은 **메일 링크로 열린 탭 B**인데 거기서 저장 방식을 지정하지 않고 있었다. → 브라우저를 닫으면 로그인이 풀려 매번 인증 메일을 받아야 했다.

- 링크 탭에서 `browserLocalPersistence` 명시
- '로그인 유지' 선택값 기억(`pms_stay_logged_in`) → 링크 탭이 같은 방식으로 저장
- 로그인 화면 문구: "이 PC에서 로그인 유지 (다음부터 인증 메일 없이 바로 접속)"
- 로그인 에러 메시지에 원인 코드 표시(미매핑 코드 진단용)

구글 로그인은 팝업 방식이라 원래 이 문제와 무관 — 확인 완료.

### 5. 프로젝트 완전 삭제 (신설)
`deleteRow()` 함수는 있었으나 **호출하는 버튼이 0개**여서 테스트 행조차 지울 수 없었다. 우클릭 메뉴에 관리자 전용 '프로젝트 완전 삭제' 추가(확인창 + 백로그 기록).
평소 운영은 진행현황을 '삭제'로 바꾸는 soft delete 권장 — 확인창에 안내 문구 포함.

### 10. 공정률 수치 검산 (화면 숫자 근거 확인)
그래프의 6월 10% / 7월 81% / 8월 85%를 코드 로직 그대로 재현해 **완전 일치** 확인.

```
공정률 = (PLC% + ETOS% + HMI% + 자체시운전% + 통합시운전%) ÷ 5
  · PLC·ETOS·HMI = 그 달까지의 최신 %(없으면 직전 값 이월)
  · 시운전% = 누적 포인트 ÷ 총점 × 100
  · 도면입수·I/O Map·화면작성·기준정보 4개는 진척률 계산에서 제외(6/17 규칙)

6월 = (0+0+0 + 55/200=27.5 + 44/200=22.0) ÷ 5 = 9.9  → 10%
7월 = (77+80+90 + 165/200=82.5 + 154/200=77.0) ÷ 5 = 81.3 → 81%
8월 = (77+80+90 + 176/200=88.0 + 176/200=88.0) ÷ 5 = 84.6 → 85%
```
요약카드의 '공정률(금월)'은 **데이터가 있는 마지막 달** 기준(이번 달이 아님).
