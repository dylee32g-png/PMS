### 2. ★키인·이동 속도 근본 개선 — 창 렌더링(화면 근처 행만 그리기)

### 3. ★일괄 저장 때 장부(팝업) 기록 소실 수리 — "PLC·ETOS·HMI 동기화 안 됨"의 원인

### 4. 드래그 범위 선택 → Del 일괄 지우기 (엑셀식)
- 마우스로 칸 범위 드래그(파란 하이라이트 — **DOM에만 칠해 재렌더 0**) → Del = 초안으로 일괄 적재(렌더 1회) → [저장]으로 확정.
- 자동 제외: NAS/수식/미적용 잠금 칸 · 드롭다운 칸(진행현황·담당자 등) · 실행번호(하위 s 마커) · 하위 합계 자동 포인트. Esc = 선택 해제.

### 5. 지우기 동기화 + "0 = 지우기" 통일 (팀장님 확정)
- 종전(7/10 설계)은 "빈칸 저장 = 장부 안 건드림"이라 지워도 팝업이 그대로였음(원설계, 드래그와 무관).
- 수리: **메인표에서 지우면(한 칸·드래그 모두) 장부 '이번 주' 기록 삭제** — 지난 주·지난 달 이력은 보존("이번에 넣은 걸 되돌린다").
- **0 입력 = 지우기(빈칸) 통일**: 팝업 규칙(7/10)을 메인표에도 — 대상 = 공정률 7개·Point·**포인트(총점)**. Point 0 키인 시 감소 차단 경고 혼란도 해소.
- 왕복 검증: 키인→저장→팝업 일치 → 드래그 Del→저장→팝업 빈칸·진척률 '—'. 001은 포인트 100, 나머지 빈칸으로 원상 정리.
