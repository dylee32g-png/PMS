## 2. P9(010행) 규칙 — 등록값 확정

파일1 `01 진행현황_P9_10…CNS_260420.xlsx` 시트 `#1 L1 진행현황` 구조:
4행 [P9] 라벨 → **5행 P9 요약행** → 7~13행 P9 패널 7개 → **14행 P10 요약행** → 16~33행 P10 패널 18개.

- **PLC = 셀 `L5,M5` · 평균 · 소수 1** → 예상 **98.6** (현재 손입력 90은 옛값 — 등록 즉시 덮임, 의도된 동작)
- **ETOS = 등록 불필요** — P9 블록에 ETOS 장비 없음 (HC900·XGR·XGT뿐). ETOS 장비는 24·25행 = P10 블록이라 011행 규칙이 이미 읽음
- **하위 공종표 = 표준 규칙 그대로 작동** — 공종 6개(공조·대기·DI/IW·RUW·WWT·FFU) + 총계 26행, HMI 31.6(손입력 32와 일치). 규칙 등록 시 subCreate가 하위 6행 자동 생성
- 분석 신뢰 근거: 기존 P10 규칙을 같은 파일로 재계산 → PLC 91.0 · ETOS 75.0 = **화면(91·75)과 정확히 일치**
- 참고: ① 011행 PLC 규칙(L5,M5,L14,M14)은 P9 요약까지 포함한 전체 평균으로 잡혀 있음(의도 확인 필요) ② 시트에 패널 행이 추가되면 아래 블록이 밀려 고정 셀 주소가 어긋남(구조 한계)
- **등록 순서**: NAS 반영 → 클라우드에 `P9 AP4 Infra 보완투자` 폴더 만들어 진척자료 업로드(★맨 위 금지 — '진척자료' 조각이 P10 규칙과 겹쳐 오배정 위험) → [지금 확인] 1회(폴더 인식) → 010행 폴더 지정 → [+ 하위 공종표 규칙] → [+ 규칙 추가] PLC·L5,M5·평균 → [지금 확인] 검증
