## 2. ★신기능 — 공용 폴더 (P9·P10 공용 파일, NAS 방식에서 최초 해결)
- **문제**: P9 PLC 파일(`01 진행현황_P9_10…CNS`)이 **011(P10) 폴더** 안에 있어, 010 행 허가증(자기 폴더)만으로는 못 읽음. 7/31 리더의 "전용은 폴더·공통은 맨 위" 해법이 NAS(브라우저 읽기)에는 없었음 — 오늘 처음 직면.
- **해결(행별 보조 허가증)**: 모달 [공용 폴더(선택)] 신설 — **자기 폴더에서 먼저 찾고, 없는 파일만 공용 폴더에서** 찾는다(같은 이름조각 오배정 방지). 허가증 키 = 기본키+`::shared`(PC별 IndexedDB). 공용 미지정 행은 100% 기존 동작(하위 호환).
- **표시(전 PC 공통)**: 반영 기록(lastApplied)에 `shared` 저장 → 규칙 칩 · 찾은 원본 파일 · 마지막 자동 반영에 보라 **`공용` 배지** (클라우드 공유라 모든 PC에서 보임).
- **열기**: **공용 폴더 주소 칸(전 직원 공통·관리자 편집)** 신설 — 010 모달에서 공용 파일을 바로 [엑셀로 열기]·[경로 복사] (011로 건너갈 필요 없음). 주소는 **남의 폴더를 빌려 읽는 행(010)에만** 넣고 011은 비움.
- **검증**: 오프라인 시뮬 7/7(선택 폴백) + 7/7(주소 변환) + 실기기(PLC 98.6 반영·배지·열기).
- **폐기**: '공용 메모' 칸은 만들었다가 배지와 중복이라 **제거** (팀장님 결정).

## 3. ★버그 수리 — 실적 그래프 유령 칸 (누적 3,377 > 총점 1,221)
- **증상**: 010 그래프 누적 3,377pt(총점 초과·달성률 100%로 캡), 진행실적 팝업은 350으로 정상.
- **원인**: 재등록 시행착오 때 P10 공종표(8칸)가 010 장부에 한 번 기록 → P9 공종표(6칸)가 앞 6칸만 덮어 **sub_6(FFU 3,027)·sub_7 잔존**. 팝업 = 하위 행 수만큼 합산이라 안 보이고, 그래프 = 문서의 sub_* 전부 합산이라 부풀음 (350+3,027=3,377 — 산수·코드 양쪽으로 확정).
- **수리(자기교정)**: 하위별 통합 반영 시 **하위 개수 밖 sub키 자동 삭제** + 유령이 있으면 값이 같아도 반영 제안 발생. 시뮬 8/8. [지금 확인]→[모두 반영] 1회로 수리 완료 → 그래프 350/1,221=29% 정상 확인.
- **재발 방지**: 같은 실수를 반복해도 다음 반영 때 자동 정리됨.
