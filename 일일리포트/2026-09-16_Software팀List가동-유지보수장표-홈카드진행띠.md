**수리** = 붙여넣기도 초안으로 전환 (`__new: true` 새 행 초안 신설)
| 동작 | 결과 |
|---|---|
| Ctrl+V | 표 맨 아래에 노란 새 행 (저장 전) |

| [취소] | 새 행은 그냥 사라짐 (저장된 적 없으니 삭제 기록도 없음) |
| 저장 전 우클릭 [완전 삭제] | 초안에서만 제거 (서버 접근 없음) |
| 화면 이동·F5 | 미저장 새 행 있으면 경고 |

## 결정·근거
1. **유지보수 = 별도 장부(A안)** — 한 표에 섞으면 개발 행에서 접수일·요청 내용·처리 내용이 전부 빈칸이 되고 상단 건수가 섞인다. 별도 장부는 카드 파일 하나로 끝나고 화면 코드 재사용 0줄.
2. **열 자리를 개발 장부와 1:1로** (팀장님 "너무 다르다") — 두 화면을 오갈 때 눈이 같은 자리를 찾도록.
3. **진행 현황 자동은 '보조'** — 개발 분류/공정률을 고칠 때만 작동하고, 사람이 정한 완료·삭제·Hold는 절대 덮지 않는다. 자동이 사람 판단을 이기면 신뢰를 잃는다.
4. **홈 도넛 삭제 + 진행 띠** — 임원이 이 화면에서 하는 일은 팀끼리 견주는 것인데 숫자만으로는 147과 45가 같은 크기로 보인다. 띠는 훑기만 해도 길이가 비교된다. 도넛이 하던 '비율'을 **건수 비중**으로 대신하면 4팀 모두 값이 있어 `—`가 사라진다.
5. **붙여넣기도 초안으로** — 같은 표에서 같은 손놀림인데 어떤 것은 확인을 받고 어떤 것은 바로 저장되면 규칙이 아니라 함정이다.
6. **완료 색 = 초록(홈), 빨강(List 칩)** — 홈은 '얼마나 됐나'를 읽는 자리라 초록이 맞고, List 칩은 기존 회사 관행을 유지. 팀장님 확인 대기 항목으로 남김.
