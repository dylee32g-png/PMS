7/30에 NAS 동기화를 끄면서 규칙 등록 모달도 같이 숨겨져, **새 프로젝트에 규칙을 붙일 방법이 없던 상태**를 해결.

- **스위치 분리** — `NAS_SYNC_ENABLED`(브라우저 파일읽기·자동반영·칸잠금)는 그대로 끄고, 화면만 켜는 `RULE_UI_ENABLED = true` 신설.
- **★삭제 사고 차단** — `extRulesOf`는 NAS 스위치가 꺼져 있으면 **무조건 빈 배열**을 반환. 이 상태로 모달이 규칙 목록을 그리면 "등록된 규칙 없음"으로 보이고, 거기에 규칙 하나를 추가·저장하면 **기존 규칙이 통째로 삭제**된다. → `extRulesRawOf`(스위치 무관 원본 읽기) 신설, 모달 전체를 이걸로 교체.
- **모달 오피스365용 정리** — NAS 전용 UI(폴더 주소 2칸·폴더 지정/변경·이 PC 지정 해제·엑셀로 열기·찾은 원본 파일)를 `NAS_SYNC_ENABLED &&`로 감싸 숨김. **지운 게 아니라 감싼 것**이라 NAS 방식 복구 시 스위치 하나로 되살아남. 섹션 번호는 `secNo()`로 자동 매김(숨겨져도 ①②③ 안 끊김).
- **자동 반영기 상태 표시** — 리더가 매 회차 Firestore(`pmsReaderStatus/{team}`)에 상태 1건 기록 → PMS가 실시간 구독(onSnapshot). 모달 상단 + 표 하단 배지 두 곳. 신호등 기준은 **마지막 확인이 주기의 2.5배보다 오래되면 '멈춘 듯'(주황)**, 오류 기록 시 빨강.

### 추가 — 프로젝트별 폴더 구조 (팀장님 결정, 완료)

프로젝트가 늘면 한 폴더에 파일이 40개씩 쌓이고, 어느 모달을 열어도 남의 파일이 다 보이는 문제.

```
PMS진척자료 /
   ├─ 01 진행현황_P9_10 …_CNS_260420.xlsx   ← 맨 위 = 공통 자리 (P9·P10 공용)
   ├─ P10 AP4 Infra 보완투자 /              ← 프로젝트 폴더
   │      진척자료_260706.xlsx
   └─ Backup / 백업 / Archive / 보관 /       ← 자동 제외
```

- 리더 `list_folder`를 **하위 폴더 재귀**로 변경(최대 5단계), 파일마다 `rel`·`dir` 부여.
- 행마다 `_extSync.folder` 지정 → 규칙은 **그 폴더(와 하위) + 맨 위(공통)** 에서만 파일을 찾음.
- PMS 모달에 폴더 드롭다운(**리더가 실제로 찾은 폴더만** 목록에 나옴 → 오타 불가). 지정 폴더가 사라지면 "클라우드에 없는 폴더!" 표시.
- 파일 목록도 폴더 기준으로 좁히고, 맨 위 파일엔 노란 **`공통`** 배지, 이 프로젝트 규칙이 읽는 파일엔 파란 **`이 프로젝트가 읽음`** 배지. `↓ 폴더 전체 보기` 토글.
- 폴더 미지정 행은 **예전과 100% 동일하게 동작**(하위 호환) → 011행 무중단 전환.
