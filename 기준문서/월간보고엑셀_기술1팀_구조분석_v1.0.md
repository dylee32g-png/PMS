## 1. 시트 5장의 역할

| 시트 | 역할 | 규모 |
|---|---|---|
| **금월** | 메인 표 (파주/해외 전체, 2018~2026 누적 147행) — 이번 달 갱신본 | 5~153행 + 하단 블록 155~173행 |
| **전월** | 금월의 **지난달 복사본(스냅샷)** — 다른 칸 단 29개 | 동일 구조 |
| **구미** | 구미 지역판 — 금월과 같은 구조(열만 1칸씩 밀림, 월 1~12, 기준셀 C2) | ~80행 |
| **년도별수량** | 자동 집계 — COUNTIF/SUMIF로 금월+구미 시트에서 연도별 건수·Point·누적 | 유일한 시트 간 수식 |
| **잔여작업** | 빈 틀 (헤더만) | — |

## 2. ★전월/금월이 넘어가는 방식 = "시트 복사", 수식 연결 아님

- 두 시트를 잇는 수식 **0건** (전수 검색). 차이는 **29칸**뿐:
  - `D2` (기준 월): 금월=7, 전월=6 ← **이 한 칸이 모든 전월/금월 열을 좌우**
  - 나머지 28칸 = 그 달 갱신분 (상태 변경 5건·% 갱신·월칸 추가·신규 행 26-13 추가)
- **매달 루틴(역산)**: ① 금월 시트를 복사해 '전월'로 보존 ② 금월 D2를 +1 ③ 그 달 값 키인

## 3. 계산 엔진 — 월별 매트릭스 + HLOOKUP (핵심)

각 행 오른쪽에 **월별 매트릭스 2벌**이 숨어 있음:
- `AA~AM` = 월 0~12 **자체시운전 수량** (그 달 실적)
- `AN~AZ` = 월 0~12 **전체공정률(%)** (그 달 시점 값)

| 자동 칸 | 수식 | 뜻 |
|---|---|---|
| V (시운전 누적) | `=SUM(AA:AM)` | 월칸 전부 합 |
| W / X (시운전 전월/금월) | `=HLOOKUP($D$2-1 / $D$2, 매트릭스, 행)` | **D2만 바꾸면 자동 재조회** |
| Y / Z (공정률 전월/금월) | 같은 방식 (AN~AZ에서) | 〃 |
| P (공증률 %) | `=SUM(I:M)/COUNTA(I:M)` | **5개 % 평균(빈칸 제외)** — 웹 기술2팀 공정률 5개 평균과 동일 사상 |
| BB (잔여 수량) | `=H(Point)−V(누적)` | |
| 년도별수량 시트 전체 | COUNTIF/SUMIF (실행번호 앞 2자리=연도) | |

**손입력 칸** = I~M(PLC·ETOS T/S·HMI·자체·통합 %, 304칸), H(Point), 월별 매트릭스의 그 달 칸, 상태(D)·날짜·내용·ISSUE.

## 4. ★하단 블록(155~173행) = 웹 List와 겹치는 구간

- 아직 실행 전(예상·견적·보류·패찰·DROP) 프로젝트 — **A열에 수행번호 26-01~26-13** = **웹 기술1팀 List의 수행번호와 동일 체계** (견적번호 C열도 26-K0715 등 List 견적코드와 동일)
- 즉 월간보고 상단(실행 확정, 실행번호 18-C003 형식)은 과거 이력, **하단 블록이 웹 List 12행과 겹침** → 연결 키 = **수행번호(1순위) + 견적번호(보조)**

## 5. List 진척율 → 월간보고 연계 방안 비교

| 안 | 방식 | 장점 | 단점/위험 |
|---|---|---|---|
| **A. 월말 내보내기(추천)** | 웹 List에 [월간보고 내보내기] 버튼 → 수행번호별 5개%·시운전 수량·공정률을 월간보고 열 순서대로 뽑아줌 → 담당자가 엑셀에 붙여넣기 | 수식·양식 완전 보존(원본 무접촉) · 구현 작음 · 운영 단순(월 1회 5분) | 붙여넣기 수작업 1회 남음 |
| B. 리더가 엑셀에 직접 쓰기 | pms-reader(openpyxl)로 월간보고 셀 기록 | 완전 자동 | **수식 계산값 소실 전례**(7/27 재저장만으로 15,558개) · 행 위치 변동 시 오기록 · 리더 재가동 필요 → **비추천** |
| C. 역방향(엑셀→웹 읽기) | NAS 읽기 규칙 재사용 | 검증된 안전 패턴 | 방향이 반대(이번 요구 아님) — 참고만 |
| D. 웹이 월간보고 전체 생성 | 템플릿 통째 생성 | — | 과거 147행+수식+서식 재현 부담 · Excel-first와 충돌 → **비추천** |

### 추천 = A안 2단계
1. **1단계**: [월간보고 내보내기] — 이번 달 값 표(수행번호·D상태·I~M 5개%·그 달 시운전 수량·그 달 공정률)를 클립보드/미니 엑셀로. 담당자는 하단 블록에 값만 붙여넣기.
2. **2단계(선택)**: 웹에 '월별 스냅샷'(매달 말 값 저장) 축적 → 내보내기를 **AA~AZ 월별 매트릭스 모양 그대로** 제공(열 순서 일치 → 통째 붙여넣기 1번). 웹 키인이 진행실적 주간장부에 역방향 기록되는지(기술1팀 열 이름 매칭)는 구현 때 확인.
