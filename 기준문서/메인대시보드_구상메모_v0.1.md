# 메인 화면 대시보드 구상 메모 v0.1

- 작성: 2026-08-11 (팀장님 아이디어 — **아직 미결정. 참고용 기록만. 나중에 팀장님과 함께 정한다**)
- 배경: 현재 메인(홈) 화면이 팀 입장 카드만 있어 심심함. **월말 보고 때 각 팀의 중요 정보가 대시보드 형식으로 한눈에** 보이면 좋겠다는 의견.
- 참고 자료: monday.com 대시보드 화면 (2026-08-11 캡처 구경) — 숫자 카드(건수) / 상태별 파이 / 담당자별 막대 / 지연·마감일별 막대 구성.

## 우리 데이터로 "지금 바로" 계산 가능한 위젯 후보
(전부 이미 Firestore에 있는 List 행·진행실적 장부에서 파생 — 새 입력·엑셀 변경 불필요)

| 위젯 | 계산 근거 | 비고 |
|------|-----------|------|
| 팀별 진행중 건수 (큰 숫자 카드) | List 행 상태 필터 | monday 상단 숫자 카드 느낌 |
| 상태 분포 도넛 | 진행현황 칸 집계 | 팀별 색은 listStatusColors 재사용 |
| 공정률 구간 분포 / 평균 | 총진척률·공정률(%) 칸 | 간부용 핵심 — "몇 건이 90% 이상인가" |
| 포인트 달성률 (누적÷총점) | 실적그래프와 동일 계산 재사용 | 이미 검증된 수치 (예: 22% = 3,766÷17,230) |
| 금월 신규·금월완료 건수 | isNewThisMonth / isCompletedThisMonth 재사용 | C-4 자동표시 로직 그대로 |
| 담당자별 담당 건수 | 담당자 칩 집계(assigneeCountMap 방식) | 기술1팀은 '수행' 칸 (팀 카드 규칙) |

## 디자인 참고 조각 (팀장님 "괜찮다" 표시한 것)
- **움직이는 아이콘 (미세 애니메이션)** — airtable.com 첫 화면 상단의 점 패턴이 은은하게 움직이는 연출 (2026-08-11). 우리 홈 화면 로고/타이틀에 과하지 않은 미세 애니메이션 후보. ※간부용이므로 '은은하게'가 핵심 — 정신없는 움직임 금지.

## 배치 후보 (미결정)
- A안: 홈 팀 카드 **안에** 미니 지표 2~3개 (카드가 곧 요약)
- B안: 홈 하단에 **팀 통합 대시보드 구역** 추가
- C안: 별도 '대시보드' 화면 (monday처럼 위젯 페이지, 간부용 읽기 전용)

## 함께 정할 것 (다음 논의 안건)
1. 간부가 월말에 제일 먼저 물어보는 숫자 3개가 무엇인지 (지표 선정이 디자인보다 먼저)
2. 배치 A/B/C 중 어디에
3. 읽기 전용 여부 (간부 계정은 클릭 없이 보기만?)
4. 갱신 시점 표시 (실시간 vs "8월 말 기준" 고정 스냅샷)

## 불변 원칙 (기존과 동일)
- 엑셀 업로드·보존 병합 로직 무접촉, 표시 전용 파생 계산만
- 원복 가능하게 (스위치/백업)
- List 메인표 한 줄 펼침 기준 불변
