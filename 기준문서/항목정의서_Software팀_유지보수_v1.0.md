# Software팀 유지보수 장표 항목정의서 v1.0 (2026-09-16)

- 작성: 염경록 팀장 / Claude · 코드 짝: `src/teamProfiles/swMaint.js`
- 표준 양식: `SW 개발현황/Software팀_유지보수_양식_v1.0.xlsx` — 시트 **"2026"**(13열, 견본 2건) + 시트 **"작성예시"**(안내, 업로드 자동 제외)
- 개발 장부(`기준문서/항목정의서_Software팀_v1.0.md`)와 **완전히 다른 장부**: 저장 공간·백업·건수가 서로 안 섞임. 화면 코드는 같은 것을 그대로 씀(새 화면 0줄).

## 1. 무엇을 적는 장표인가
현장에서 들어오는 **A/S · 프로그램 수정 요청**을 받은 순서대로 적는 접수 대장.
개발 프로젝트(UMS 64bit 전환 같은 건)는 **프로젝트 List**에, 하루 이틀에 끝나는 요청은 여기에 적는다.
요청이 커져 프로젝트가 되면 → 프로젝트 List에 새로 등록하고, 이 장표 비고에 그 번호를 적어 둔다.

## 2. 표준 양식 13열 (순서 = 화면 순서)
| # | 열 이름 | 칸 종류 / 규칙 |
|---|---|---|
| 1 | 번호 | 3자리(001). 병합 매칭 키. 추가 시 그 해 최대+1 자동 |
| 2 | 수행번호 | YY-NNN. 빈칸 [+] = 그 해 최대+1 자동 · ✕ 회수 · 손 키인 금지 |
| 3 | 공장 구분 | 단어 드롭다운: 공통 · 파주 · 구미 · 중국 · 베트남 (+ ✎ 직접 입력) — 개발 장부와 동일 |
| 4 | 요청자 | 자유 키인 + 그 열에 이미 쓴 값 제안 (예: 생산기술 김OO) |
| 5 | 진행 현황 | 상태 칩. 목록: 접수 · 처리중 · 완료 · 보류 · 취소 (+ ✎ 직접 입력) |
| 6 | 소스 | 단어 드롭다운: TmsLocal · TmsUmc-L · TmsLocal-VH · TmsFFU · TmsLDE — 개발 장부와 동일 |
| 7 | 요청 내용 | 여러 줄 글. '- ' 항목마다 줄 나눔 · Alt+Enter = 줄 추가 |
| 8 | 접수일 | 날짜 칸(자유 타이핑·달력). **기준월 드롭다운 기준** |
| 9 | 완료일 | 날짜 칸. **'이번 달 완료' 건수 기준** |
| 10 | 담당자 | 명단 드롭다운(다중 가능): 김준형 담당 · 윤상노 팀장 |
| 11 | 처리 내용 | 여러 줄 글. 같은 방식 |
| 12 | 구분 | 단어 드롭다운: A/S · 개선 · 설치·셋업 · 문의 |
| 13 | 비고 | 여러 줄 글 |

- ★**열 자리 = 개발 장부와 1:1** (2026-09-16 팀장님 "너무 다르다"): 두 화면을 오갈 때 칸 위치가 같도록 맞춤

| 개발 장부(프로젝트 List) | 유지보수 장표 |
|---|---|
| 번호 · 수행번호 · 공장 구분 · 요청자 · 진행 현황 · 소스 | 같음 |
| 프로젝트명 | **요청 내용** (무슨 건인지) |
| 공정률(%) | — (없음) |
| 시작일 | **접수일** |
| 완료예정·종료일 | **완료일** |
| 담당자 | 같음 |
| 진행 내용 | **처리 내용** |
| 개발 분류 | **구분** |
| 비고 | 같음 |

- 기본 고정(스크롤해도 붙어 있는 칸) = **번호 ~ 소스**(짧은 칸 6개)
- 기본 화면 맞춤 = **담당자까지** 화면 폭에 맞춤, 그 뒤 여러 줄 글은 가로 스크롤(한 줄 펼침 기준 유지)
- 없는 것: 공정률·시운전·포인트·PLC/ETOS/HMI·하위(공종)·NAS 규칙·참조(폴더)
  → 진행실적 등록·실적 그래프 메뉴는 이 장부에서 숨김(카드 `기능` 스위치). A/S는 끝났거나 아직이거나 둘 중 하나라 %가 의미 없음

## 3. 화면 · 홈 연결
- 홈 **Software팀 카드 안 [유지보수 장표] 줄** → 누르면 List 화면이 이 장부로 열림
- 그 줄 오른쪽 배지 = **미처리 N · N월 완료 N** (미처리 = 접수 + 처리중 · 완료 = 완료일이 이번 달인 건)
- List 상단 요약 = 전체 / 접수 / 처리중 / 완료 (+ 완료 옆 ▲이번 달 배지)
- 상태 칩 색 = 완료 빨강 · 처리중 초록 · 접수 앰버 · 보류·취소 회색(팀 공통 규칙)
- 헤더 제목 `Software팀 유지보수 ▾`로 개발 장부와 서로 전환
- 그대로 쓰는 기능: 칸 키인·드롭다운·날짜 달력·여러 줄·노란 초안 [저장]·헤더 ▼ 필터/정렬·검색·상세 팝업·행 복사·엑셀 업로드/생성/반영·열 폭·틀고정·백로그·[월간 마감]

## 4. 결정·근거 (2026-09-16 팀장님)
- **A안(별도 장부) 채택**: 프로젝트 List에 섞으면 접수일·요청 내용·처리 내용 칸이 개발 프로젝트 행에서 전부 빈칸이 되고 상단 건수도 섞인다. 별도 장부는 카드 파일 하나로 끝나고 화면 코드는 0줄.
- **열 = 초안 12개 + 수행번호 = 13개** (완료일·담당자는 초안에 이미 있던 항목)
- **공장 구분·소스·담당자는 개발 장부와 같은 목록**을 그대로 사용 — 두 장표의 말이 갈리지 않게
- **로그인 직행 보호**: 김준형·윤상노가 두 장부 명단에 겹쳐 '어느 팀인지 모름'이 되는 것을 막으려 카드에 `보조장부: true` — 로그인 직행 판정에서만 빠지고 장부·백업·팀 전환에는 포함
- **백업**: 자동·수동 전체 백업에 이 장부가 한 벌 더 포함(3팀 + 개발 + 유지보수 = 5벌)
- **수행번호는 장부마다 따로 셈**: 개발 26-001과 유지보수 26-001은 서로 다른 건. 한 줄로 묶으려면 별도 협의 필요

## 5. 업로드(파서) 규칙 — 카드 `파서옵션`
| 규칙 | 값 |
|---|---|
| 시트 | 이름에 연도가 있는 시트("2026")만 읽음 — '작성예시' 시트는 자동 제외 |
| 머리글 | 3행 1층 고정(행1 제목·행2 날짜/작성자 건너뜀) |
| 데이터 행 | 4행부터 1행=1건. **접수일 빈 행 제외**(여분 틀) |
| 번호 | 1 → 001 |
| 날짜 | 날짜 셀·글자 모두 YYYY-MM-DD |
| 관리자 열 | 자동 삽입 안 함 |

## 6. 첫 사용 순서
1. ⚙ → [엑셀 업로드] → `SW 개발현황/Software팀_유지보수_양식_v1.0.xlsx`
2. [엑셀 확정 저장] — 표 구조(13열)가 이때 만들어짐
3. 견본 2건(001·002)은 우클릭 [완전 삭제]로 지우거나, 실제 건으로 덮어써서 사용
4. 이후에는 웹에서 [+ 추가]로 바로 접수 등록(엑셀 없이 운영 가능)
