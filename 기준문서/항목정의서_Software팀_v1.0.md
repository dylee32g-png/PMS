## 4. 결정·근거 (2026-09-16)
- **1행=1프로젝트로 전환**: 원본 4줄 묶음은 기술팀 파서·병합·백업·엑셀 반영이 못 읽음. 표를 평평하게 하면 기술팀 기능 전부가 코드 추가 없이 그대로 쓰임(팀 카드 방식).
- **진행 현황 값·기입 규칙 (2026-09-16 2차·4차)**: 값 5종 = 수정중·개발중·완료·삭제·Hold. 칩 색 = 수정중 파랑 · 개발중 초록 · 완료 빨강 · Hold/삭제 회색(개발 분류가 칩 색으로도 갈림).
- **진행 현황 자동 따라가기 (4차, 카드 `상태자동`)**: 개발 분류·공정률을 고치면 진행 현황이 규칙대로 같이 바뀐다 — 프로그램 수정 → 수정중 / 프로그램 개발 → 개발중, 공정률 100% 이상 → 완료. 사람이 적어 둔 **완료·삭제·Hold는 자동이 덮지 않는다**(`유지`). 동작 지점 = 셀 키인 · 드롭다운 선택 · 상세/추가 팝업 저장, 그리고 이미 쌓인 행은 설정 **[진행 현황 규칙 맞춤]** 한 번으로 통일(관리자·진행 현황 칸만 저장).
- **진행 현황 입력 방식 (2·4차)**: 2차에는 키인 전용(일반입력열)이었으나 삭제·Hold를 고를 데가 없어 **목록 + [✎ 직접 입력]**으로 바꿈(카드 `일반입력열: []`). 목록 = 마스터 5종 + 그 열에 실제 쓰인 값. [✎ 직접 입력]을 누르면 종전처럼 키인 — 목록에 없는 값도 그대로 저장된다.
- **공정률 단일 열**: 상단 카드·홈 카드는 공용 폴백(‘공정률’ 이름 열 평균)으로 자동 계산. % 막대는 isPctCol에 '공정률' 추가.
- **날짜 키워드 추가**: 공용 isDateCol에 '시작일'·'종료일' — 기술2팀 옛 시트에도 같은 이름이 있어 무해(오히려 달력 지원).
- **메인표 '진행 내용' 여러 줄 (2026-09-16 3차 지시)**: 한 줄로 이어 붙어 읽기 어려움 → 팀 카드 `여러줄열`에 적은 열만 '- ' 항목마다 줄을 나눠 표시(값은 그대로, 보여주기만 나눔). ★메인표 한 줄 펼침 불변 기준(CLAUDE.md)은 다른 팀·다른 열에 그대로 유지. 편집은 엑셀과 동일하게 Alt+Enter(·Shift+Enter) = 줄 추가이며, '- '로 시작하는 줄에서는 새 줄에도 '- '가 자동으로 붙는다. 행 높이가 제각각이 되므로 이 팀은 창 렌더(모든 행 높이가 같다고 보는 속도 최적화)를 끈다(80행 이상에서만 쓰던 기능).
- **과거 연도(2020~2025) 적재는 보류**: 4줄 묶음 서식이라 변환기가 먼저 필요. 카드 `연도별적재:false`.
